# WordPress Full Stack — 35-Day Learning Tracker

An interactive, browser-based learning tracker for a 35-day WordPress Full Stack Developer job-preparation plan.

## Includes
- PHP and OOP, WordPress Core, custom plugin development
- JavaScript ES6+, REST API and AJAX, MySQL and SQL
- WooCommerce, Git, security and deployment
- 30 interview questions for each of 8 subjects (240 total)
- YouTube learning resources and official documentation
- Topic completion tracking, answer notes, confidence ratings, and JSON export/import

## Enable GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. After GitHub finishes publishing, the site URL will be `https://shadow037.github.io/igi/`.

Progress is saved in the visitor's browser using local storage. Use Export progress to back it up or transfer it to another browser.
